# Turning off ad personalization and promo content (no ADB)

These steps use only the phone's Settings. They need no computer and change nothing that Reboot
manages. Menu names differ by Android version and brand, so use the search box in Settings if a path
is missing.

## Any Android phone (Google ad settings)

Look for one of these, depending on the version:

- Settings, Google, **Ads**, then **Delete advertising ID** (newer versions) or
  **Opt out of Ads Personalization** (older versions).
- Settings, Security & privacy (or Privacy), **Ads**.

Deleting the advertising ID stops apps from using it for personalized ads. It does not remove ads.

## Also worth checking

- **Lock screen**: look for a "wallpaper carousel", "glance", "magazine" or "news" feature and turn it
  off.
- **Home screen**: swipe to the far-left page; many brands let you disable the news/feed page from
  home screen settings.
- **System apps with recommendations**: in Settings, search for "recommendations", "suggestions",
  "promotions" or "personalized services" and turn them off.
- **Notifications**: in Settings, Notifications, review which system apps may send promotional
  notifications and turn off the ones you do not want.
